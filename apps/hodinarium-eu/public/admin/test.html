CSH editor pomocníci — testovací stránka

Tato stránka slouží pro lokální vývoj a smoke test spell-checkeru a AI našeptávače bez nutnosti přihlášení do Sveltia CMS (které volá GitHub OAuth + Cloudflare Access proxy a v lokálním dev běhu obvykle nezadne).

Tip: klikni vlevo dole na ⚙ Pomocníci a zapni co chceš testovat. Default vše OFF — žádný surprise. Po zapnutí stáhne spell-checker ~6 MB cs Hunspell dict (jednorázově, cached browser). AI vyžaduje běžící backend (lokálně Ollama přes wrangler pages dev — viz .dev.vars.example).

Test 1 — spell-checker

Napiš text s úmyslnými chybami nebo anglicismy:

Po zapnutí spell-checkeru by se měly podtrhat: balanc (anglicismus → správně „setrvačka", které je v slovníku), pružinkou (slovo „vlasová pružinka" je nestandardní forma, ale „pružinkou" by mělo být OK v cs dictu).

Slova která nesmí být podtržená: Krečmer (custom CSH dict), setrvačka, kotvou, kyvadlo, Holešovic.

Test 2 — AI našeptávač

Začni rozepsanou větu (bez tečky na konci) a zastavte na ~1.2 s. AI by měla nabídnout pokračování jako ghost-text:

Tab přijme návrh, Esc odmítne. Status v pravém dolním rohu ukáže stav (loading / suggesting / error).

Diagnostika

Otevři DevTools console (F12). Po zapnutí v Pomocnících uvidíš:

  • [csh-spell] Loading nspell + cs_CZ Hunspell dict…
  • [csh-spell] Ready. Base cs dict + 1242 custom CSH words.

Settings se ukládají v localStorage['csh-editor-settings']. Reset: localStorage.removeItem('csh-editor-settings') v console.
