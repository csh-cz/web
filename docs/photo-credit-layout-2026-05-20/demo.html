Photo credit layout — návrh

Čtyři scénáře. Layout se volí class modifikátorem (build-time z image-sizes.json — w/h + délka creditu), žádné runtime JS měření. Grid + writing-mode, bez absolutního pozicování.

1. Landscape — credit pod obrázkem

Default. <figure class="photo"> bez modifikátoru. Caption v grid řádku pod obrázkem.

2. Portrait + krátký credit — pod obrázkem

Portrait, ale credit krátký → stále pod obrázkem (vejde se). class="photo is-portrait".

3. Portrait + delší credit — svisle vpravo

Portrait + delší credit → class="photo is-portrait layout-side". Caption svisle vpravo přes writing-mode: vertical-rl, lemuje pravý okraj obrázku.

4. Velký portrait — centrovaný na šířku textu

class="photo is-portrait is-large". Centrováno margin-inline: auto, výška omezena max-height: 80vh.

Rozhodovací logika (build-time)

V Photo.astro z image-sizes.json:

const isPortrait = h > w * 1.15;          // výrazně na výšku
const isLarge    = w >= 900 || h >= 1200; // velký obrázek
const creditLen  = (author + license + sourceUrl).length;

const layoutClass = [
  'photo',
  isPortrait && 'is-portrait',
  isLarge && 'is-large',
  // svisle vpravo jen když: portrait + delší credit + NE velký-centro
  (isPortrait && !isLarge && creditLen > 24) && 'layout-side',
].filter(Boolean).join(' ');
