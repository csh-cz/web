## Výklad

**Minutový pastorek** (Bureš 1965 *pastorek minutového kola*) je pastorek na **centrálním hřídeli** stroje, sedící na stejném hřídeli jako [minutové kolo](/slovnik/minutove-kolo) — odsud jeho jméno. Jeho funkce je předat pohyb z hnací větve (lanový buben se závažím, případně přes přísadní kola u delších strojů) do [jicího soukolí](/slovnik/jici-stroj).

### Pozice v kaskádě (Martínek–Řehoř 1964, obr. 46)

**Jednodenní stroj** (krátká doba chodu):
```
hnací kolo  →  minutový pastorek  =na společném hřídeli=  minutové kolo  →  ...
```

**Týdenní/osmidenní stroj** (delší doba chodu):
```
hnací kolo  →  přísadní kolo + pastorek  →  minutový pastorek  =na společném hřídeli=  minutové kolo  →  ...
```

### Bureš 1965 — definiční tabulka

Bureš 1965 v učebnici „Hodinové stroje I" pro 1. ročník hodinářského učebního oboru zavádí **kanonickou tabulku tří skupin pojmenování kol** (s. 152, obr. 42):

| I. skupina (sekundové soukolí) | II. skupina (ručkové soukolí) | III. skupina (hnací soukolí) |
|---|---|---|
| 1. minutové kolo | 1. ručkový pastorek | 1. hnací kolo závažové nebo perové |
| 2. pastorek mezilehlého kola | 2. střídné kolo | 2. pastorek vloženého kola |
| 3. mezilehlé kolo | 3. pastorek střídného kola | 3. vložené kolo |
| 4. pastorek sekundového kola | 4. hodinové kolo | **4. pastorek minutového kola** |
| 5. sekundové kolo | | |
| 6. pastorek krokového kola | | |

Minutový pastorek je tedy v III. skupině jako **rozhraní mezi hnacím soukolím a sekundovým soukolím** (které začíná minutovým kolem).

## Reference

> „I když je základním typem hodinového stroje stroj jednodenní, použijeme pro schéma a pojmenování jednotlivých kol **stroj osmidenní**. **III. skupina: 4 — pastorek minutového kola**."
> — BUREŠ, Josef. *Hodinové stroje I.* SPN, Praha 1965, s. 152, obr. 42.

> „Je-li doba chodu krátká (např. u jednodenních), zabírá hnací kolo přímo do **minutového pastorku** (obr. 46) a II. soukolí se skládá z jedné záběrové dvojice. U strojů s delší dobou chodu bývá vloženo mezi hnací kolo a minutový pastorek jedno až dvě **přísadní kola s pastorkem**."
> — MARTÍNEK, Bohumil – ŘEHOŘ, Jaroslav. *Základy hodinářství.* SNTL, Praha 1964, s. 68.
